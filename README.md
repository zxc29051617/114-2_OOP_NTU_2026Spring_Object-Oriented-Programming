# NTU Object-Oriented Programming 2026 Spring

這個 repository 收錄臺大 114-2 物件導向程式語言（黃乾綱老師）課程的 OOP Judge 作業，以 Java 實作。
每個資料夾對應一題，資料夾名稱是題號。

繳交方式：[`OOP JUDGE 繳交作業步驟說明 2026v1.pdf`](<OOP JUDGE 繳交作業步驟說明 2026v1.pdf>)

| 題號 | 內容 | 檔案 |
|---|---|---|
| 1 | 兩個整數相加 | `APlusB.java` |
| 2 | 判斷閏年 | `IsLeapYear.java` |
| 3 | Green crud 的族群成長 | `GreenCrud.java` |
| 4 | 刪除與取代句子中的字 | `SentenceProcessor.java` |
| 5 | 檢查括號是否正確配對 | `ParenthesisMatcher.java` |
| 6 | 卡牌收集與配對遊戲 | `CardMatchingGame.java` |
| 7 | 選課系統：加選、退選、列出課程 | `CourseSelectionSystem.java` |
| 8 | 依類型建立圓形、正方形、三角形 | `Shape.java`、`ShapeFactory.java`、`Circle.java`、`Square.java`、`Triangle.java` |
| 9 | 簡易計算機與自訂例外 | `SimpleCalculator.java`、`UnknownCmdException.java` |
| 10 | ATM 提款服務與例外處理 | `ATMService.java`、`SimpleATMService.java`、`Account.java`、`ATMException.java` |
| 19 | 依類型建立圖形（與第 8 題相同） | `Shape.java`、`ShapeFactory.java`、`Circle.java`、`Square.java`、`Triangle.java` |
